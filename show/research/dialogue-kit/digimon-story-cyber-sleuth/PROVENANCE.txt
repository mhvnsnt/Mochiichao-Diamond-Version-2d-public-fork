*** WHAT THIS FOLDER IS — AND IS NOT ***
This folder contains the TEXT-TABLE SCHEMA for the game, NOT extracted dialogue
lines. No GitHub-hosted repo was found that ships Cyber Sleuth / Hacker's Memory's
actual extracted dialogue text with stated provenance (see ../GAP.md for the full
check list). What the canonical tooling repo DOES ship — and what is copied here —
is the complete reverse-engineered structure definitions for every .mbe text/data
table in the game, which map exactly where and how all of the game's text lives.
That coverage map is the defensible deliverable available for this target.

STATED PROVENANCE (from the repo itself):
- README: the tool "provides support to pack, unpack, decrypt and encrypt various
  file formats found in games using the game engine built and used by
  Media.Vision", explicitly supporting "Digimon Story: Cyber Sleuth (DSCS)";
  "MBE Files contain a number of data tables and get extracted by the tool into
  CSV files". The structures/ folder supplies the field definitions the MBE
  unpacker requires for DSCS — reverse-engineered from the game's own .mbe files.
- Key schema: structures/dscs/message.json defines the main dialogue table as
  { ID: int, Speaker: int, Japanese: string, English: string, Chinese: string,
  EnglishCensored: string, Korean: string, German: string }.
- Other text-bearing tables defined: quest_para, digiline_para (+ digiline_constant),
  eden_text_para, farm_talk, bbs_post_para, keyword_para / keyword_message_para /
  keyword_npc_para, map_msg_entry / map_msg_explanation / map_msg_title,
  hackers_memory_para, text (custom_sound), plus all item/skill/Digimon/shop tables.
