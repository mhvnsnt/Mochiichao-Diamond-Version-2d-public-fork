STATED PROVENANCE (from the repo itself):
- README: "A work in progress decompilation of Digimon World for PS1" — a matching
  decompilation: the build dumps the original PSX Digimon World (USA) ISO, disassembles
  the original binaries, and rebuilds byte-identical binaries (make compare).
- The text/ tree holds the game's string tables in YAML, one entry per game string with
  per-release language variants (ja / en_us / en_eu). tools/gen_text.py converts each
  text/<dir>/<name>.yaml into a generated C header (build/<release>/psx/generated/text/)
  that the decompiled C includes — i.e. these YAMLs ARE the extracted game text, in the
  form the matching build consumes.

WHAT WAS EXTRACTED / COPIED HERE:
- The repo's complete text/ directory, structure preserved (text/btl, text/fish,
  text/kar, text/main, text/shop, text/std, text/trn, text/vs).
- Content: executable string tables — item names/descriptions (main/item.yaml, the
  largest file), menus/UI, map names, battle messages and command shouts, script-system
  common strings (main/script_common.yaml), fishing, curling (kar), shop, training,
  versus mode.
- COVERAGE LIMIT (important): DW1's per-map NPC/story dialogue lives in the game's
  per-map script binaries, NOT in these executable string tables, and is not in this
  bank. This is a UI/item/system-text bank, not a full dialogue dump.
- text/example.yaml is the gen_text.py tool's documented EXAMPLE file (synthetic
  greeting/label examples), not game text; it is kept for structure reference and
  counted separately below.
