STATED PROVENANCE (from the repo itself):
- README.md: "Poke Corpus — A tool to query the Pokemon corpus." It defines the
  two bank types searched by default as "the common text (interface text, names,
  descriptions) and the script text (story-related text, dialogue, etc.)" — i.e.
  in each game folder, <lang>_common.txt is the general game-text bank and
  <lang>_script.txt is the story/NPC dialogue bank.
- NOTES.md, section "Sources and changes made": "Most text dumps in this repo
  use the common format shared by xytext (https://github.com/kwsch/xytext),
  pk3DS (https://github.com/kwsch/pk3DS), and pkNX (https://github.com/kwsch/pkNX)."
  Those are Kurt's (kwsch / Kaphotics, Project Pokemon) named game-text
  extraction/editing tools — xytext/pk3DS for the 3DS games (Gen 6-7) and pkNX
  for the Switch games (Gen 8-9). The dumps in this repo follow that
  extraction format.
- NOTES.md also documents, in its "Format" section, exactly what representation
  changes were made to the original game data in these files: variables/functions
  are written in square brackets (e.g. [VAR 0100(0000)]), furigana as {kanji|kana},
  and the control codes are written as the escape sequences \n, \r, \c, \\, \[, \{.
  Text is otherwise presented as extracted, organised in the files as a sequence
  of numbered "Text File : <id>" blocks matching the games' internal text files.
- HONEST LIMIT: the repo gives this provenance at corpus level (sources/format
  section in NOTES.md); it does not publish a separate per-game extraction log
  or ROM hashes. That is the provenance the repo itself states, quoted above,
  and it is why this source was accepted over anonymous dumps with none.
